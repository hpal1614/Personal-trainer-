# v0.5 Beta — Readiness Report

The product is **ready to be used**, not because it's finished, but because the
core experience is coherent and reliable. This is the polish-sprint status against
the v0.5 checklist — honest, evidence-based.

---

## What v0.5 is
> A private, offline-first fitness coach that quietly helps you make better
> decisions with less effort.

**Complete habit loop:** Open → Today's Focus → Workout → Frictionless logging →
Workout Complete → Tomorrow. Five shipped features (001–005), all reviewed.

---

## Polish checklist status

| Area | Status | Notes |
|------|--------|-------|

## Performance (measured, headless Chromium)

| Metric | Result |
|--------|--------|
| Returning-user load → plan visible | **~110 ms** |
| `Store.logSet` (write) | **0.3 ms** |
| `Coach.buildPlan` | **0.1 ms** |
| `CoachBrain.getTopFocus` (full engine) | **0.6 ms** |
| Total app source | **~137 KB**, zero dependencies |

Every interaction is effectively instant. Offline verified (service worker shell).

## Fixes applied this sprint
- Accessibility: nav touch targets to 44px; `prefers-reduced-motion` media query.
- (Audit confirmed empty states, copy, perf, and a11y labels already solid — no
  churn where none was needed.)

## Honestly not done (and why)
- **Native-only polish** (Live Activities, system haptics, Dynamic Type beyond
  browser zoom) — out of scope for a PWA; deferred unless we go native.
- **Real-user validation** — the most important remaining step, and it belongs to
  people, not to us. See `BETA-TEST-PLAN.md`.

## Verdict
**Ship v0.5 Beta to real users.** The next signal should come from watching five
people who train use it for two weeks — that evidence, not a roadmap, should
define Feature 006.
